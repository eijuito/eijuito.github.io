kwiek-autogate

Sistema inteligente de automação de portões automáticos baseado em microcontroladores ESP32/ESP8266 com telemetria, acionamento seguro, integração com Home Assistant, MQTT e assistentes virtuais (Alexa / Google Assistant).

Arquitetura do Projeto

Sobre o Sistema kwiek-autogate

O kwiek-autogate foi desenvolvido para transformar portões eletrônicos convencionais em dispositivos IoT inteligentes e seguros. Oferece monitoramento em tempo real do status de abertura/fechamento (sensores magnéticos reed switch), histórico de acionamentos, protocolo fail-safe anti-esmagamento e comunicação assíncrona bidirecional criptografada.

ESP32 / ESP8266 Home Assistant (MQTT Discovery) Alexa & Google Assistant OTA (Over-The-Air Updates) Fail-Safe Lockout WebSockets Local WebUI

Guia de Instalação & Flash

Como Gravar o Firmware no Microcontrolador

Você pode gravar o arquivo .bin utilizando a ferramenta oficial esptool.py ou via interface web (Adafruit / ESP Web Flasher):

# Gravação no ESP32 via esptool:

esptool.py --chip esp32 --port COM3 --baud 460800 write_flash -z 0x10000 kwiek-autogate_v1.2.0_esp32_qio-40mhz.bin


# Gravação no ESP8266:

esptool.py --chip esp8266 --port COM3 write_flash 0x0 kwiek-autogate_v1.2.0_esp8266_flash4m.bin

💡 Após o primeiro flash, as atualizações subsequentes podem ser realizadas via OTA diretamente pela interface web do portão.
