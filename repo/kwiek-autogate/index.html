kwiek-autogate

Controlador industrial de portões eletrônicos e relés para Raspberry Pi desenvolvido em Rust nativo de alta performance. Arquitetura resiliente Supervisor/Worker com watchdog autônomo, acionamento por interrupção física GPIO de baixa latência e atualizações remotas seguras sem parada de serviço.

Arquitetura de Alta Disponibilidade (Rust Embedded)

Sobre o Sistema kwiek-autogate

O kwiek-autogate é uma solução de nível industrial projetada para automação e controle crítico de portões, iluminação e acessos em Raspberry Pi (ARM64 / ARMv7). Construído inteiramente em Rust, opera sob o padrão desacoplado Supervisor / Worker: um daemon permanente com watchdog automático que gerencia o ciclo de vida, licenciamento por Hardware ID e telemetria, enquanto o motor de execução controla diretamente os relés (active-low) e as interrupções de hardware dos botões físicos com debounce sub-milissegundo, garantindo máxima imunidade a travamentos e segurança operacional fail-safe.

Rust 2021 (Native Binary) Raspberry Pi (ARM64 / aarch64) Supervisor / Worker Architecture Zero-Downtime Hot Reload Hardware GPIO Interrupts (rppal) Hardware ID Licensing Active-Low Relay Shield (BCM 26, 20, 21) Debounced Physical Buttons (BCM 5, 6, 12, 13)

Instalação Oficial Automatizada (systemd)

Instalação com Comando Único no Raspberry Pi

O script oficial realiza o download dos binários compilados em Rust, instala de forma isolada em /opt/kwiek-autogate (sem poluir a pasta do usuário) e registra o daemon permanente no systemd com inicialização automática no boot:

curl -fsSL https://eijuito.github.io/repo/kwiek-autogate/install.sh | sudo bash

💡 Após a execução, o painel de controle estará disponível imediatamente em http://<IP_DO_PI>:8000.
