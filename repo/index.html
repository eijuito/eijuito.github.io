Catálogo dinâmico de artefatos com integridade criptográfica SHA-256 e detecção automatizada de repositórios.

Diretrizes & Governança do Vault

Padrões de Nomenclatura, Integridade & Políticas de Uso

📦 1. Nomenclatura Semântica

Os artefatos seguem o padrão previsível SemVer com identificação de plataforma e arquitetura de destino: 

<projeto>_<versao>_<plataforma>_<arch>.<ext>
  • IoT / Firmware: sensor_v1.0.3_esp32.bin
  • Java Enterprise: service_v2.1.0_all.jar
  • Trading MQL5: scalper_v3.2_mt5_x64.ex5

🔒 2. Integridade & Checksums

Cada binário possui seu hash SHA-256 criptográfico gerado automaticamente no build para auditoria contra corrupção ou adulteração:

PowerShell:

Get-FileHash .\arquivo.bin -Algorithm SHA256

Linux / macOS:

sha256sum -c SHA256SUMS

🛡️ 3. Políticas & Governança

  • Imutabilidade: Versões publicadas nunca são sobrescritas; correções incrementam o patch SemVer.
  • Zero Leaks: Proibição estrita de credenciais, senhas Wi-Fi, tokens ou chaves privadas nos artefatos públicos.
  • Crawler Dinâmico: Pastas e arquivos adicionados em repo/ são indexados automaticamente via GitHub Actions.
  • Limites de Volume: Arquivos ≤ 50 MB via Git; volumes maiores são vinculados via GitHub Releases.
